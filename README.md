# Barcode & QR Code Scanner

Scans QR codes live from the webcam using OpenCV's QRCodeDetector and highlights the decoded content.

Part of a series of beginner-friendly OpenCV projects.

## Setup

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## Usage

```bash
python main.py
python main.py --image qr.png
```

Press `q` to quit any live window.
